# 知识库插件 2.0.3

> 这一版**只改插件与文档**，配置项与知识库数据格式没有变化，直接覆盖安装即可。

安装：Zotero → 工具 → 插件 → 齿轮 → **Install Plugin From File…** → 选本页的
`zotero-kb-2.0.3.xpi`。往 profile 的 `extensions\` 丢 xpi 无效，必须走这个入口。

## 管理面板

- 「**高级**」页新增「**索引重建**」：**增量更新**只处理有变化的文献；**全部重建**会把全库
  重新切片、重算向量（危险动作，点了会二次确认）。两者都在后台跑，进度写在下方的运行日志里，
  可以直接关掉面板等它跑完。
- 「高级」页新增「**维护动作**」：**环境自检**（Python / MinerU / Ollama 与磁盘体检）、
  **备份索引**、**对账巡检**（只读，列出知识库与 Zotero 之间对不上的地方）。
- 修复「知识库结构」页的「刷新」按钮点了没有反应。其余带"刷新"字样的按钮本来就各自有真实
  的刷新路径，这次一并核对过。
- 提示文案修正：原先有几处让用户去点并不存在的按钮（例如"手动更新"、"启动 Ollama"），
  现在都改成照着做能成的说法；同一个动作在不同地方出现的按钮名也统一了。

## 文档

- 合并掉重复的文档：设计与用法全部并入 [ARCHITECTURE.md](../ARCHITECTURE.md)，
  知识库层级与目录树并入 [INSTALL.md](../INSTALL.md)。仓库现在只剩 `README.md`、
  `INSTALL.md`、`ARCHITECTURE.md` 与本说明。
- 通读校对了一遍，修正了与现在实现不符的说法（面板上有什么按钮与页签、右键菜单项、
  设置项、本地模型相关数字等）。
- `INSTALL.md` 补上分节纲要与模型窗口的两个关键数字：每节正文上限 **9000 字**、
  提示词约 **800 字**，并明确推荐本地模型的上下文开到 **16384**。

## 已知限制

（与 2.0.0 起相同）

- DSH 侧直读 `index.db` 只能读到原始字段值；权重这类算出来的字段要走引擎，不要在前端
  复刻一遍算法。
- 与早期那个常驻的本地服务相比，少了"从别的程序随时 curl 一下"这条路 —— 这是有意去掉的。
- MinerU 相关的全量测试没有跑（会长时间占满机器）。
