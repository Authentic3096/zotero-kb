# 知识库插件 2.0.8

> 优化项目下载使用方式。

安装顺序调整为：**先装 Zotero 插件**，再跑 `scripts\install-env.cmd` 装前置依赖，
首次建库在 Zotero「知识库管理 → 高级 → 全部重建」里完成（不用先跑
`1-convert.cmd`）。普通用户下载 **`zotero-kb-2.0.8-win64.zip`** 即可，里面已经带
运行代码、脚本、Skill 与 `zotero-kb-2.0.8.xpi`。

安装：Zotero → 工具 → 插件 → 齿轮 → **Install Plugin From File…** → 选包里的
`zotero-kb-2.0.8.xpi`；装完完全退出 Zotero 再打开。详细步骤见
[QUICKSTART.md](../QUICKSTART.md)。
