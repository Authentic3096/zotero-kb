# 知识库插件 2.0.5

> 这一版清掉了上一代「本机服务」架构的全部遗留，并把插件设置与可选组件安装都收进管理面板；
> 知识库数据格式没有变化，直接覆盖安装即可。

安装：Zotero → 工具 → 插件 → 齿轮 → **Install Plugin From File…** → 选本页的
`zotero-kb-2.0.5.xpi`。往 profile 的 `extensions\` 丢 xpi 无效，必须走这个入口。

## 管理面板

- **左侧导航重排**：知识库结构 → PDF 解析 → 分节纲要 → 经验库 → 元数据 → 分类建议 →
  损坏查询 → 运行环境 → 偏好设置 → 高级 → 提示词
- **可选组件的安装入口**：「偏好设置 → 可选组件安装引导」里现在能直接装 ——
  Ollama（打开下载页 / 拉取推荐模型）、MinerU（开始安装 / 重新安装）。
  安装是后台任务，输出逐行显示；失败会保留原因，不会"点完没反应"
- **正文字号**：改成直接填数值（px，10–20），改完**已打开的侧栏立刻生效**；
  侧栏不再有档位选择
- 运行环境页去掉了一句多余的小字

## 架构清理

- 上一代的本机 HTTP 服务整条链**移除**：回退启动、开机自启、任务队列、通行证文件都不再存在；
  引擎与面板只走 Zotero 插件自己的无端口通道
- 修复若干已知问题
