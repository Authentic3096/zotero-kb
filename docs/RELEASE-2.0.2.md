# 知识库插件 2.0.2

> 这一版**只改插件与文档**，配置项与知识库数据格式没有变化，直接覆盖安装即可。
> 升级之后**已有的纲要不会自动重建**：想让旧文献用上新的"跳过参考文献、每节上限更大"，
> 在管理面板「分节纲要」页对要更新的文献重新生成一次即可。

安装：Zotero → 工具 → 插件 → 齿轮 → **Install Plugin From File…** → 选本页的
`zotero-kb-2.0.2.xpi`。往 profile 的 `extensions\` 丢 xpi 无效，必须走这个入口。

## 设置面板

- 去掉「本地服务地址」与「访问 token」两个输入框。它们对应的是早期版本用过的本地服务，
  那个服务早已停用、插件也不再依赖它；留着只会让人以为要启动什么。
- 「知识库位置」不再经由那个服务读取，改由插件自己的引擎回答 —— 服务停着也能正常显示，
  旁边的「打开这个目录」「迁移到 Zotero 数据目录」同样如此；迁移完成的提示改成
  "重启 Zotero 后生效"。
- 删掉「内容窗格『本地模型』」那一块（一个勾选项、一个上下文窗口输入框和一段说明）：
  它描述的内容窗格聊天早已下线，对应的配置项也不存在了，改它不会有效果。

## 本地模型

- 「用哪个本地模型」的列表改由引擎读取，不再依赖那个本地服务；失败提示改成可以照着做的
  说法（先确认 Ollama 在跑、给出地址与安装入口）。
- 列表默认**只列名字带上下文后缀的模型**（如 `-4k` / `-16k` / `-24k`），并在下面写清后缀
  对应的窗口大小；有一个勾选项可以关掉这个过滤。没有后缀的模型看不出窗口多大，容易挑错。
- 去掉了「自动选」这一项：只有一个模型时直接用它；有多个时按"推荐的那一系优先、同系里
  窗口大的在前"排好，默认选中第一个并标注推荐，也可以自己选别的。

## 分节纲要

- **跳过参考文献类小节**：这类小节常常是全文最长的几节，问模型纯属浪费。判据补上了中文字
  之间的空格与两种词序（实际来自论文的标题经常写成 `参 考 文 献` 或"文献参考"），另外也认
  `bibliography`、`works cited` 这类写法。按本机库统计，这类小节约占十分之一。
- **每节正文上限从 5000 字提到 9000 字，模型窗口从 8192 提到 16384**。切节器本身就在
  9000 字处切，两处对齐之后，长节基本不再被截断（此前约 14% 的节会被截掉尾部）。
  这两个值是绑在一起的，代码与仓库侧检查里都写了断言：只改一个会让检查失败。

## 文档

`INSTALL.md` 新增「本地模型与上下文（建议用派生模型）」一节：为什么建议用 `ollama create`
把上下文做进模型、Modelfile 与命令示例、命名约定，以及推荐值 —— 并说明插件发请求时会带上
自己的窗口设置（会覆盖模型里的值），所以模型名后缀主要是给不显式设置窗口的客户端看的。

## 已知限制

与 2.0.0 相同：

- DSH 侧直读 `index.db` 只能读原始字段值，权重这类算出来的字段要看就得走引擎，
  不要在前端复刻一遍算法。
- 有几条写入成功路径没有在真机上验过（只验过出错路径，没有往真库里写测试数据）：
  分类建议、阅读器侧栏保存、运行环境保存。
- 有两处交互没有在真机验过：经验库编辑弹窗里再叠一层对话框、下拉替代控件的实际展开。
- 与早期那个常驻的本地服务相比，少了"从别的程序随时 curl 一下"这条路，这是有意去掉的。
- MinerU 相关的全量测试没有跑（会长时间占满机器）。
