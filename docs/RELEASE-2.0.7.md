# 知识库插件 2.0.7

> 优化项目下载使用方式。

普通用户现在下载 **`zotero-kb-2.0.7-win64.zip`** 即可（运行代码、脚本、Skill 与
`zotero-kb-2.0.7.xpi` 都在包里），不用再下整个源码；升级用包里的
`scripts\update.cmd`，`.venv`、知识库数据与 Zotero 设置都保留。

安装：Zotero → 工具 → 插件 → 齿轮 → **Install Plugin From File…** → 选包里的
`zotero-kb-2.0.7.xpi`；装完完全退出 Zotero 再打开。详细步骤见
[QUICKSTART.md](../QUICKSTART.md)。
