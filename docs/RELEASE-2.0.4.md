# 知识库插件 2.0.4

> 这一版把**插件设置**收进管理面板，并整理了面板的显示细节；知识库数据格式没有变化，直接覆盖安装即可。

安装：Zotero → 工具 → 插件 → 齿轮 → **Install Plugin From File…** → 选本页的
`zotero-kb-2.0.4.xpi`。往 profile 的 `extensions\` 丢 xpi 无效，必须走这个入口。

## 设置只留一处

- Zotero「设置 → 文献知识库」那一栏**下线**：所有开关搬进管理面板的新页「**偏好设置**」——
  知识库行为、侧栏「知识库」的层级与字号、知识库同步、知识库位置、可选组件安装引导、
  任务通道（排查用）
- **模型选择**并入「运行环境 → 模型配置」，沿用原来更好用的规则：本机 Ollama 时**只列名字带
  上下文大小后缀**的模型（例如 `qwen3:4b-instruct-24k`），当前在用的模型永远留在列表里
- 模型配置的权威来源统一为一处，老设置启动时自动并入（只补缺、不覆盖）

## 面板显示

- 「运行环境」页八行改为定宽网格：路径用等宽字体、过长时**中段省略**（悬停可看全路径），
  来源 / 状态 / 按钮各列对齐
- 「**重启引擎**」现在会真的停掉引擎进程，下一次请求自动拉起；有任务在跑时不会硬停
