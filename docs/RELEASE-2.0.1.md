# 知识库插件 2.0.1

> 这一版只改文案：设置页里有几处说明把 Markdown 的强调标记原样写进了界面，
> 另有几句提示还在讲已经停用的旧通道。功能、配置与知识库数据格式都没有变化，
> 直接覆盖安装即可。

安装：Zotero → 工具 → 插件 → 齿轮 → **Install Plugin From File…** → 选本页的
`zotero-kb-2.0.1.xpi`。往 profile 的 `extensions\` 丢 xpi 无效，必须走这个入口。

## 修了什么

Zotero 的偏好页不解析 Markdown，所以那些写成 `**这样**` 的说明，在界面上会显示成
一对星号。这一版把它们改成正常的加粗显示，一共六处，分布在：

- 「知识库位置」里关于迁移的那句说明；
- 「跨机同步」说明里的"不能"；
- 「从 DSH 导入文献」的两处说明；
- 「本地模型」那一段里的两处说明。

「本地服务地址」下面那句提示也重写了。它原来还在讲插件早期用过的本地服务与某个内部阶段的
编号，现在改成：这个地址对应的是早期版本的本地服务，已经停用、插件不依赖它，
确实需要时手动运行 `scripts\4-service.vbs`。

## 兼容性

与 2.0.0 相同：Zotero 7 ~ 11（9 和 10 都装得上），配置项与知识库数据格式不变，
升级不需要额外动作。

## 已知限制

与 2.0.0 相同：

- DSH 侧直读 `index.db` 只能读原始字段值，权重这类算出来的字段要看就得走引擎，
  不要在前端复刻一遍算法。
- 有几条写入成功路径没有在真机上验过（只验过出错路径，没有往真库里写测试数据）：
  分类建议、阅读器侧栏保存、运行环境保存。
- 有两处交互没有在真机验过：经验库编辑弹窗里再叠一层对话框、下拉替代控件的实际展开。
- 与早期那个常驻的本地服务相比，少了"从别的程序随时 curl 一下"这条路，这是有意去掉的。
- MinerU 相关的全量测试没有跑（会长时间占满机器）。
