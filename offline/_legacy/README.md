# 已废弃的模块

这里的东西**不要**在新代码里 import。留着只是为了查历史。

## `adjudicate_chunks.py`

**废弃原因**：它实现的是"让本地模型逐切片裁决哪几个坏"，
而这套判据在 2026-10-03 被全库实测推翻：

- 全库 3681 个切片判坏 2223 个（60%），抽查发现判坏的"坏切片"里
  大量是**正常正文** —— 中文正文、封面、参考文献、公式矩阵
- 对照实验（同一批切片、同一模型、**只换取样方式**）：上轮判**好**的
  90 个切片重判仍有 25% 被判坏 —— 判定本身不稳定，与取样无关
- 判坏率按正文来源看完全一样（zotero-cache 60% / pymupdf 61%）——
  不是来源坏了，是判据坏了

**替代品**：
- 文献级解析健康检查 → `offline/check_chunks.py`（判据全是客观量）
- 缓存 vs PyMuPDF 的取舍 → `zreader.arbitrate_by_model()`（两段并排比较，
  比"让模型独立打分"可靠得多）
- 正文修复 → `zreader._deshift_fix()`（字符偏移还原）+ `repair_chunks.py`（逐篇重建）

它还会 `from check_chunks import ...` 旧接口（`rule_flags` / `chunk_quality` 表），
那些都已经不存在了，直接 import 会报错。
